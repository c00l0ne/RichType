# Руководство RichType

[На главную](../README.md)

## Первый запуск

Соберите приложение командой `build.cmd`, затем запустите `dist\RichType\RichType.exe`. На главном экране выберите CPU или NVIDIA GPU и нажмите **Скачать и запустить**. Дождитесь готовности модели и включите **Исправлять автоматически**.

По умолчанию используется Qwen3.5 2B. В дополнительных настройках доступна меньшая модель Qwen3.5 0.8B. CPU-режим по умолчанию использует два потока; это число потоков, а не ограничение процента загрузки процессора. Скорость зависит от оборудования, модели и длины очереди.

Обычный запуск показывает окно. Ключ `--tray` скрывает его сразу после запуска. Автозапуск Windows приложение самостоятельно не добавляет.

## Как обрабатывается набор

Законченные слова попадают на проверку после пробела или разделителя. Последнее слово без пробела проверяется после паузы от 350 мс. Если задана большая задержка, используется она. По умолчанию начальная задержка обычной проверки — 250 мс; к ней добавляется время ответа модели.

Во время обычного набора новые символы остаются в очереди. Она хранит до 2048 символов и обрабатывает части до 160 символов. При переполнении очередь сбрасывается с сообщением. Если модель работает медленнее набора, ожидание может увеличиваться.

Win+Space, Ctrl+Alt, Alt+Shift и Ctrl+Shift сохраняют очередь. Во время удержания сочетания текущая проверка приостанавливается; после отпускания клавиш и закрытия переключателя языка она возобновляется. Пробел из Win+Space не добавляется в текст очереди. Перед заменой повторно проверяются поле, исходный текст и курсор. Эти изменения вошли в 0.8.33; отдельного тестового прогона для них не было.

Клик, навигация, смена поля, вставка и неподдерживаемый ввод могут сбрасывать очередь. Backspace и Delete отменяют устаревшую проверку. Сокращённое слово остаётся без автоматической замены до продолжения набора. После ручного редактирования старого слова приложение читает его целиком вокруг курсора.

Enter не задерживается и не воспроизводится повторно. Если приложение отправило сообщение и очистило поле, исправление уже отправленного текста пропускается. Текст, существовавший до запуска или вставленный из буфера, автоматически не исправляется.

## Настройки

**Дополнительные настройки** открывают выбор движка и модели, список приложений, задержку, тайм-аут, потоки CPU и исключения.

Разрешённые приложения задаются именами процессов без `.exe`, через запятую. По умолчанию это `notepad, chrome, msedge, firefox, telegram`. Разрешение не гарантирует, что конкретное поле поддерживает нужный интерфейс доступности Windows.

В **Не исправлять эти слова** добавляются слова и имена, которые нужно сохранять. Регистр не важен. Проверку раскладки и проверку пробелов и дефисов можно отключать отдельно.

Кнопка **Инструкции ИИ** открывает восемь редактируемых инструкций. **Применить сейчас** сохраняет изменения и очищает кэш. При необходимости увеличить контекст встроенная модель перезапускается автоматически.

## Отмена, пауза и выход

| Действие | Управление |
|---|---|
| Отменить последнюю замену | Ctrl+Alt+Z, пока ввод и фокус не изменились |
| Приостановить или включить | Ctrl+Alt+F8 либо меню значка |
| Вернуться к настройкам | Скрытые значки возле часов → RichType → Открыть RichType |
| Завершить программу и её движок | Меню значка → Выход |

Обычный Ctrl+Z управляется редактором и может отменить целую группу операций. Для отмены RichType используйте Ctrl+Alt+Z. Если горячая клавиша занята другим приложением, RichType сообщает об этом.

Закрытие окна оставляет приложение и модель в фоне. Выход через меню завершает только автоматически запущенный приложением движок. Отдельный сервер Ollama не завершается.

## Другой локальный сервер

Основной режим самостоятельно загружает и запускает llama.cpp. Дополнительно поддерживаются локальный Ollama и сервер с совместимым API `/v1/chat/completions`, например llama.cpp или LM Studio.

В дополнительных настройках выберите **Другой локальный сервер**, задайте корневой адрес вроде `http://127.0.0.1:8080` без `/v1` и имя загруженной модели. Допустимы только локальные адреса, без логина, пароля, параметров запроса и перенаправлений. В этом режиме CPU/GPU и размер контекста настраиваются в самом сервере.

## Где хранятся файлы

Для совместимости с ранними версиями настройки, скачанные веса и движок находятся в `%LOCALAPPDATA%\Kazrich`. Это стандартная локальная папка Windows, которую приложение определяет автоматически. Мьютекс единственного экземпляра также совместим с ранними версиями: одновременно запускать старый Kazrich и RichType не нужно.

В репозиторий эти данные не входят. Очередь и кэш исправлений находятся в памяти. После первоначальной загрузки основной режим работает без интернета и API-ключа.

## Ограничения

Нужен редактируемый элемент с Windows UI Automation TextPattern. Парольные поля, поля только для чтения, выделенный текст, неподдерживаемые направления письма и неподтверждённые позиции курсора пропускаются. Эти проверки зависят от корректных свойств самого редактора.

Сильно испорченный текст, ошибки между двумя существующими словами и неоднозначные фразы могут остаться без исправления или исправиться неверно. RichType не является проверкой всей грамматики документа. Скорость из отдельных измерений нельзя переносить на любое оборудование.

При ошибке модели исходный текст сохраняется; последующий ввод может повторить проверку. При неполной замене со стороны Windows приложение ставит автокоррекцию на паузу и сообщает об этом.
