# RichType

**Печатайте на русском и английском. Исправляйте опечатки и раскладку локально.**

RichType — фоновый ИИ-автокорректор для Windows на C# / .NET 10. Он замечает опечатки в текущем наборе, проверяет неверную раскладку и дефисное написание через локальную модель Qwen3.5. Работает на CPU или NVIDIA GPU; после первой загрузки интернет и API-ключ не нужны.

Название обыгрывает ник **Kazrich**, участника форума, предложившего идею проекта, и английское *type* — «печатать». На этапе разработки проект назывался Kazrich.

**Версия 0.8.33 · Windows x64 · Русский + English · MIT**

[Как запустить](#быстрый-запуск) · [Настройки](docs/USAGE.md) · [Результаты проверок](docs/VALIDATION.md) · [Статистика разработки](docs/DEVELOPMENT_STATS.md)

## Что умеет

| Задача | Пример |
|---|---|
| Исправить небольшую русскую опечатку | `првиет` → `привет` |
| Исправить английскую опечатку | `helllo` → `hello` |
| Восстановить раскладку | `ghbdtn` → `привет` |
| Проверить дефисное написание | `какому нибудь` → `какому-нибудь` |
| Продолжить обработку после смены языка | Очередь сохраняется при Win+Space и сочетаниях модификаторов |
| Перепроверить слово после ручной правки | Читается целое слово вокруг курсора |

Законченные слова проверяются после разделителя, последнее слово — после паузы. Пока модель работает, можно продолжать печатать: следующие слова остаются в очереди. Перед заменой приложение повторно проверяет поле, исходный текст и курсор. Последнюю замену можно отменить собственной горячей клавишей.

Качество зависит от модели и контекста. Примеры показывают ожидаемое поведение, а не гарантию исправления любой фразы.

## Быстрый запуск

В репозитории находятся исходники и документация. Готовые EXE, DLL, установщики и веса модели не публикуются.

1. Установите [.NET 10 SDK для Windows x64](https://dotnet.microsoft.com/download/dotnet/10.0). Нужен **SDK**, полной Visual Studio не требуется.
2. Скачайте исходники через **Code → Download ZIP** и распакуйте их. Либо клонируйте репозиторий:

   ```powershell
   git clone https://github.com/c00l0ne/RichType.git
   cd RichType
   ```

3. Откройте PowerShell в папке с `build.cmd` и соберите приложение:

   ```powershell
   .\build.cmd
   ```

4. Запустите результат сборки:

   ```powershell
   .\dist\RichType\RichType.exe
   ```

5. В окне RichType выберите **CPU** или **NVIDIA GPU**, затем нажмите **Скачать и запустить**. По умолчанию выбрана Qwen3.5 2B. Дождитесь сообщения о готовности локальной модели.
6. Убедитесь, что включено **Исправлять автоматически**, и напечатайте `ghbdtn ` в поле приложения. Вставка текста из буфера не запускает коррекцию.

При следующих запусках установленная модель запускается автоматически. Выбор GPU требует совместимой видеокарты NVIDIA и драйвера. Если переносите свою сборку на другой компьютер, копируйте всю папку `dist\RichType` вместе с библиотеками рядом с EXE.

### Что скачивается при первом запуске

| Компонент | Примерный размер |
|---|---:|
| Qwen3.5 2B, GGUF Q4_K_M | 1,28 ГБ |
| Движок для CPU | 18 МБ |
| Движок и библиотеки CUDA | 0,54 ГБ |

Приложение использует закреплённые версии файлов и проверяет SHA-256. Веса скачиваются с Hugging Face, движок llama.cpp — из GitHub Releases. Эти загрузки происходят на компьютере пользователя и не являются вложениями этого репозитория.

## Где настройки и значок

Обычный запуск открывает окно настроек. Его закрытие сворачивает RichType в системный трей. Если значок не виден, откройте **скрытые значки возле часов**, нажмите значок правой кнопкой и выберите **Открыть RichType**.

| Действие | Клавиши или меню |
|---|---|
| Отменить последнюю замену | **Ctrl+Alt+Z** |
| Включить или приостановить коррекцию | **Ctrl+Alt+F8** |
| Настроить приложения и исключения | **Дополнительные настройки** |
| Изменить инструкции локальной модели | **Инструкции ИИ** |
| Полностью завершить работу | Значок в трее → **Выход** |

В [руководстве](docs/USAGE.md) описаны задержка, очередь, переключение языка и подключение другого локального сервера.

## Приватность и совместимость

Обработка идёт через локальный сервер. Приложение принимает только адреса loopback и не поддерживает пересылку набранного текста в облачный API. Очередь и кэш исправлений находятся в памяти. Модели и пользовательские настройки хранятся отдельно от исходников.

Для чтения поля и курсора используется **Windows UI Automation TextPattern**. Совместимость зависит от конкретного редактора: работа во всех приложениях не подтверждена. Парольные поля, поля только для чтения и неподтверждённые позиции ввода пропускаются; это зависит от свойств, которые предоставляет само приложение. Повышенные права целевого приложения и нестандартные редакторы могут мешать работе.

По умолчанию разрешены процессы `notepad`, `chrome`, `msedge`, `firefox` и `telegram`. Этот список задаёт разрешение на обработку, а не подтверждает поддержку каждого поля в этих программах.

## Структура исходников

| Папка | Содержимое |
|---|---|
| `src/Kazrich.Core` | Правила обработки текста, очередь, клиент модели, настройки |
| `src/Kazrich.App` | Интерфейс, наблюдение ввода, UI Automation, локальный движок |
| `tests` | Исходники проверок логики, модели и интерфейса |
| `docs` | Руководство, результаты проверок и статистика |

Имена внутренних проектов сохранены для совместимости с исходниками периода Kazrich. Скрипты `build.cmd`, `test.cmd` и `pack-source.ps1` — текстовый исходный код; сборка не запускает тесты автоматически.

Код распространяется по [лицензии MIT](LICENSE). Внешние модель и движок распространяются отдельно на условиях их авторов.
