# Статистика разработки RichType

[На главную](../README.md)

Историческая сводка за **10 сентября 2026 года**, когда проект разрабатывался под названием Kazrich. Числа перенесены из предоставленного автором отчёта. Общие счётчики относятся к одному срезу; сведения о версии дополнены последующими результатами. Часовые отметки, часовой пояс, местоположение, локальные пути и данные лимитов аккаунта не публикуются.

Это статистика создания проекта с ИИ-агентом, а не потребление токенов и ресурсов установленным RichType. Сырые журналы и переписка в репозиторий не включены.

## Скорость и наблюдавшиеся задержки

| Показатель | Значение |
|---|---|
| Выходные токены / оценённое время генерации | ≈41,5 токена/с |
| Ожидание первого токена, 83 завершённых хода | Медиана 3,27 с; максимум 38,07 с; суммарно 7:28 |
| Один поздний эпизод исправления дефиса | 5:47 до прерывания; рассуждения 3:55, команды 3,4 с |
| Один поздний ответ во время приостановки работы | 1:40, включая 1:25 рассуждений; команды не запускались |

В этих поздних эпизодах основную задержку давали длительные рассуждения. Прекращение тестовых прогонов не устраняло эту часть ожидания. Это наблюдение по отдельным эпизодам, а не характеристика задержки каждого ответа или каждого исправления RichType.

Одна автоматическая команда обновления была отклонена с сообщением `blocked by policy` без подробной причины. В дальнейшем установка исходной версии 0.8.33 была завершена через обычный выход из приложения и замену файлов.
